Glisser un point : déplacer. Glisser le vide : se déplacer. Molette : zoom (Maj+molette : largeur du point). Double-clic sur un tracé : ajouter un point. Ctrl+clic : ajouter un point après le point choisi (dessiner ; sur un tracé vide, commence la route). Suppr : retirer le point. Carrés jaunes : début / fin des embranchements (glisser). Bleu = route, rouge = chemins secondaires, gris = murs / collision, vert = conduite. Triangle blanc = sens.
