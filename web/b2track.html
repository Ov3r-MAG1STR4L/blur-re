Conduite
Surfaces (couche « surfaces praticables ») : « Nouvelle surface » puis un clic par sommet ; Entrée ou clic sur le 1er sommet = fermer, Échap = arrêter. Glisser un sommet : déplacer. Double-clic sur un bord : insérer un sommet. Ctrl+clic : sommet ajouté après le sommet choisi. Suppr : retirer le sommet. Clic dans une surface : la choisir (nom, type, exportable). Indépendantes des trajectoires : rien n'est exporté à cette étape.
Trajectoires : glisser un point : déplacer. Glisser le vide : se déplacer. Molette : zoom (Maj+molette : largeur du point). Double-clic sur un tracé : ajouter un point. Ctrl+clic : ajouter un point après le point choisi (dessiner ; sur un tracé vide, commence la route). Suppr : retirer le point. Carrés jaunes : début / fin des embranchements (glisser). Bleu = route, rouge = chemins secondaires, gris = murs / collision, vert = conduite. Triangle blanc = sens. Conduite : lancer « Blur2DubaiTest\Lancer avec enregistrement.bat », choisir la route, rouler ; « en direct » montre les positions au fur et à mesure.
