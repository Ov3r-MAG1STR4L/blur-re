Reverse Studio : mode d'emploi

À quoi ça sert. Voir une route inversée telle que le jeu la recevra (tracé, grille de départ, bonus, caméra d'intro), la retoucher, puis la verrouiller une fois validée en jeu pour qu'aucun build ne la casse.

1. Choisir la route dans le menu (rangé par lieu, avec le nom du jeu).

2. Se déplacer : bouton droit = tourner, molette = zoom, bouton du milieu = glisser la vue, T = vue de dessus (la plus fiable pour juger une place).

3. Sélectionner : clic sur une voiture, un bonus ou un texte ; glisser dans le vide = cadre de sélection ; Maj + clic ou cadre = ajouter ; Ctrl+A = tout ce qui est visible ; Échap = rien.

4. Retoucher : G déplacer, R tourner (poignée 3D), « Remettre l'objet » pour revenir à l'origine ; Ctrl+Z / Ctrl+Y annuler / rétablir ; Ctrl+S enregistrer.

5. Lire la grille : chaque voiture porte son numéro et une flèche blanche vers l'avant ; le panneau donne son écart au centre et au bord. Couleurs : vert = posée, rouge = en l'air ou sous le sol, gris = sol inconnu, bleu = retouchée. « Grille affichée » : multi (celle de la course perso) ou solo.

6. Caméra d'intro : « Aperçu » rejoue le survol et le plan de grille du jeu. Les routes inversées reprennent les caméras de l'original : si le plan de grille montre une route vide, la grille a bougé. Pour la refaire : choisir le plan, placer la vue comme la caméra doit voir, P (ajouter ce point de vue), recommencer pour 2 à 5 points ; « Aperçu » montre le résultat ; « Enregistrer la caméra ». La caméra passe en douceur par les points, dans l'ordre. « Caméra du jeu » revient à l'originale.

7. Vers le jeu : les retouches enregistrées sont appliquées au prochain make_reverse, puis à tester dans la copie du jeu. Route bonne en jeu → « Verrouiller » : les builds suivants la remettent à l'identique.

Contrôles (panneau) : rouge = à corriger, vert = bon, gris = information.
